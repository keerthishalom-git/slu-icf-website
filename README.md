# SLU Indian Christian Fellowship website

Static site, one file: `index.html`. No build step.

## Deploy on Vercel
Option A (GitHub): push this folder to a GitHub repo, then on vercel.com → Add New → Project → import the repo → Framework preset "Other" → Deploy.
Option B (CLI): in this folder run `npx vercel` and then `npx vercel --prod`.

Before going live, replace every [PLACEHOLDER] in index.html (times, rooms, dates, social links).
